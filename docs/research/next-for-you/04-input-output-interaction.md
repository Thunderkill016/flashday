# 04 — Input, output & interaction balance

## Framework evidence

**Nation's Four Strands (2007):** a balanced course needs roughly equal
meaning-focused input, meaning-focused output, language-focused
learning, and fluency development. Not a single mechanism — a curriculum
*diet* constraint. → **MODERATE** (framework + supporting literatures).

**Incidental learning from input is real but dose-dependent.**
Uchihara, Webb & Yanagisawa (2019): repetition→incidental vocab r=0.34.
Webb/Uchihara/Yanagisawa meta: 9-18% of encountered unknown words learned
immediate, 6-17% delayed; similar across reading/listening/RwL; viewing
lower. Swanborn & de Glopper: ~15% per read. → **STRONG** that exposure
contributes; **MODERATE** on magnitude (it's small per encounter — input
must be *voluminous and repeated*, not a one-shot intro).

**Swain's output hypothesis:** pushed output does things input can't —
noticing the gap, hypothesis testing, fluency/automaticity. Pica et al.
(1989), Izumi (2002). → **MODERATE.** Justifies production_attempt and
interaction_turn as *claim-bearing* events rather than optional extras.

**Task repetition:** meta-analysis (2025): fluency improves
consistently; complexity/accuracy mixed. Repetition works through
familiarity freeing attention (cognitive load reduction). → **MODERATE**;
fluency leg is promising but kernel has no fluency contract (keep
FLUENT reserved).

**Noticing:** Schmidt's noticing hypothesis underlies NOTICE stage;
input alone doesn't guarantee uptake — attention must be drawn (input
enhancement, Izumi 2002). → **MODERATE.**

## What this means for sequencing

- Exposure/input tasks are not mere unlock-gates: they carry real
  (small, cumulative) learning value. The current rule 7/8 ordering
  (mission continuation → new capability exposure) correctly treats
  input as forward progress — and Uchihara's frequency finding says
  *repeat encounters across contexts* are the mechanism, supporting the
  kernel's VARY CONTEXT stage.
- Production is the test that proves the loop closed: output tasks are
  where INDEPENDENT evidence is minted. A diet of exposure+recognition
  never mints production evidence — policies must pull learners toward
  production/interaction, not let recognition-only learning accumulate.
- Transfer/variability is the generalization mechanism: the kernel's
  family-based transfer tasks map onto the varied-practice literature.

## Constraint for policy design

The four strands are a *session/portfolio* constraint, not a
per-decision one: no single `planNext` call can satisfy all four. The
architecture must compose sessions (or streaks of sessions) that
collectively cover strands — one decision at a time with global
coverage accounting.
